# React Learning

A collection of projects built while learning **React.js**, from the basics to routing. Each folder is a standalone Vite project.

## Projects

| Folder | Description |
|---|---|
| `02counter` | Counter app to practise `useState` |
| `03talinprops` | Reusable components with props and Tailwind CSS |
| `04bgChanger` | Background colour changer |
| `05passwordGenreter` | Random password generator |
| `06currenyConvetor` | Currency converter |
| `07reactrouter` | Multi-page app using React Router |
| `customreact` | Building a mini React from scratch |
| `vikas-react` | Practice project |

## Tech Stack

React.js, Vite, Tailwind CSS, React Router

## Run a Project

```bash
cd <project-folder>
npm install
npm run dev
```
